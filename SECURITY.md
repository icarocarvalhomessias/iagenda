# Security

IAgenda handles people's calendars and health data (medications), so security reports are taken seriously.

**Please don't open a public issue for a vulnerability.** Use GitHub's private reporting instead: the repository's **Security** tab → **Report a vulnerability**. You'll get an answer as soon as possible, and credit in the fix if you want it.

In scope: anything in this repository, including the server, the chat's locks (making the AI act outside the person's calendar, bills and medications, or skip the on-screen confirmation), sign-in and sessions, the demo mode and the Docker setup.

---
